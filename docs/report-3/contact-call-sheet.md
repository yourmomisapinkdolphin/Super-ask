# Office contacts: call sheet

The phone numbers in `data/contacts.json` were copied from each institution's own website. Nobody has called them yet. This sheet is for confirming them. Fill in a row for each call, then a teammate records the results in `data/contacts.json`.

## How to call

- Call during office hours (Monday to Friday, about 8:00–11:30 or 14:00–17:00).
- Say who you are and ask one question:
  - **Khmer:** «សួស្តី ខ្ញុំជានិស្សិតកំពុងធ្វើគម្រោងសិក្សា។ តើលេខនេះជាលេខរបស់ [ឈ្មោះស្ថាប័ន] សម្រាប់ប្រជាពលរដ្ឋសួរព័ត៌មានមែនទេ?»
  - **English:** "Hello, I'm a student working on a study project. Is this the number the public should use to ask [institution] for information?"
- If they give a better number, write it in **Notes**, including which office it is for.
- If nobody answers, try once more on another day before you write "no answer".

**Reached?:** yes / no answer / wrong number / not in service
**Right office for the public?:** yes / no (then put what they said in Notes)
